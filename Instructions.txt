PHAN 2: GIAI THICH THUAT TOAN - MULTIPLE ANT COLONY SYSTEM (MACS)
=================================================================

[cite_start]MACS su dung hai dan kien: ACS-DIST (toi thieu quang duong) va ACS-VEI (toi thieu so xe). Cac dan kien chay song song va chia se thong tin T_best[cite: 20, 99-106].

2.1 Tong quan luong cuc:
MACS la coordinator: khoi tao T_best bang nearest neighbor, xac dinh m = num vehicles.

Chay lap:

Start ACS_DIST with sigma = m (so xe hien tai).

Start ACS_VEI with sigma = m - 1 (thay doi muc tieu).

Khi ACS_VEI tim duoc giai phap feasible voi m-1 xe -> cap nhat m, reset/khong reset pheromone theo thiet ke.

ACS_DIST su dung CROSS exchange local search de cai thien quang duong.

2.2 Cac thanh phan chinh:
Ant construct solution (Algorithm 2 trong bai bao):

Tu node i, chon j in N_i^k (feasible neighbors) dua tren:

Pheromone tau_ij

Heuristic eta_ij^k

Quy tac: voi prob q0 -> chon best, nguoc lai chon theo xac suat p_ij^k.

Neu khong co feasible customer thi quay ve depot.

Neu khong du nang luong den j thi chen tram sac s = argmin_{l in F}{d_il + d_lj} (select_closest_station).

Sau khi xay dung xong, chen cac unvisited customers vao vi tri tot nhat thoa rang buoc (insertion heuristic).

Heuristic:

ACS-DIST: eta_ij^k <- 1 / max(1, (dt_j - ct_k)*(l_j - ct_k)).

ACS-VEI: eta_ij^k <- 1 / max(1, (dt_j - ct_k)*(l_j - ct_k) - in_j) ; in_j la so lan j bi bo sot.

Pheromone update:

Local: tau_ij <- (1 - xi) * tau_ij + xi * tau_0 khi di qua canh (i,j).

Global: tau_ij <- (1 - rho) * tau_ij + rho / C_bs tren cac canh cua T_bs (best-so-far).

# LocalSearch.py
from copy import deepcopy

class LocalSearch:
    def __init__(self, graph):
        self.graph = graph

    def run(self, solution, distance):
        """
        CROSS-exchange local search implementation.

        Input:
            solution: list of node indices representing full solution path
                      (ex: [0, ... ,0, ... ,0]) where each route begins and ends with depot 0.
            distance: float, total distance of solution
        Output:
            best_solution: improved solution (list)
            best_distance: improved distance
        """
        best_solution = solution[:]
        best_distance = distance

        # Split into routes (each route includes trailing depot)
        routes = self._split_routes(best_solution)

        improved = True
        # First-improvement strategy
        while improved:
            improved = False
            num_routes = len(routes)
            # iterate through unordered pairs of routes (including same route for intra-route Or-opt)
            for a in range(num_routes):
                for b in range(a, num_routes):
                    r_a = routes[a]
                    r_b = routes[b]
                    # skip trivial short routes
                    if len(r_a) <= 2 and len(r_b) <= 2:
                        continue

                    # enumerate segments in r_a and r_b (segments exclude depot endpoints)
                    for start_a in range(1, max(1, len(r_a)-1)):
                        for end_a in range(start_a, len(r_a)-1):
                            seg_a = r_a[start_a:end_a+1]

                            for start_b in range(1, max(1, len(r_b)-1)):
                                for end_b in range(start_b, len(r_b)-1):
                                    seg_b = r_b[start_b:end_b+1]

                                    # build new candidate routes
                                    new_r_a = r_a[:start_a] + seg_b + r_a[end_a+1:]
                                    new_r_b = r_b[:start_b] + seg_a + r_b[end_b+1:]

                                    # feasibility check for the two affected routes
                                    if not self._check_feasible(new_r_a):
                                        continue
                                    if not self._check_feasible(new_r_b):
                                        continue

                                    # build new routes list and compute distance
                                    new_routes = routes.copy()
                                    new_routes[a] = new_r_a
                                    new_routes[b] = new_r_b

                                    new_solution, new_distance = self._merge_routes(new_routes)

                                    if new_distance + 1e-8 < best_distance:
                                        # accept improvement
                                        best_distance = new_distance
                                        best_solution = new_solution
                                        routes = self._split_routes(best_solution)
                                        improved = True
                                        # break out to outer loop for first-improvement
                                        break
                                if improved:
                                    break
                            if improved:
                                break
                        if improved:
                            break
                    if improved:
                        break
                if improved:
                    break

        return best_solution, best_distance


    def _split_routes(self, path):
        """
        Convert full path (list) into list of routes (each route ends with depot 0).
        Example: [0,1,2,0,3,4,0] -> [[0,1,2,0], [0,3,4,0]]
        """
        routes = []
        route = []
        for node in path:
            route.append(node)
            if node == 0 and len(route) > 1:
                routes.append(route)
                route = [0]
        # Edge case: if last route wasn't appended because path doesn't end with depot - ensure it ends
        if route != [0]:
            route.append(0)
            routes.append(route)
        return routes

    def _merge_routes(self, routes):
        """
        Convert list of routes back to solution path (list) and compute total distance.
        Each route in routes should end with depot.
        """
        solution = []
        total_dist = 0.0
        for r in routes:
            # ensure route begins with depot 0
            if r[0] != 0:
                r = [0] + r
            # append all nodes except last depot to avoid duplicating depot between routes
            solution.extend(r[:-1])
            # compute distances on route
            for i in range(len(r)-1):
                total_dist += self.graph.node_dist_mat[r[i]][r[i+1]]
        # finally append trailing depot
        solution.append(0)
        return solution, total_dist


    def _check_feasible(self, route):
        """
        Check feasibility of a single route.
        Inputs:
            route: list of node indices (must start and end with depot 0)
        Checks:
            - capacity constraint (load)
            - energy constraint (battery level), allowing full recharge at stations and depot
            - time windows (ready_time/due_date) and service times
        Returns:
            True if feasible, False otherwise
        """
        # initial states
        current_load = 0.0
        current_battery = self.graph.tank_capacity
        current_time = 0.0

        # route should start with 0 (depot)
        if route[0] != 0:
            return False
        # iterate edges
        for idx in range(len(route)-1):
            cur = route[idx]
            nxt = route[idx+1]
            node_cur = self.graph.nodes[cur]
            node_nxt = self.graph.nodes[nxt]

            # distance and battery usage
            dist = self.graph.node_dist_mat[cur][nxt]
            battery_usage = dist * self.graph.fuel_consumption_rate

            # if cannot reach next node with current battery: infeasible
            if current_battery + 1e-9 < battery_usage:
                return False

            # update time and battery by travel
            travel_time = dist / self.graph.velocity
            current_time += travel_time
            current_battery -= battery_usage

            # handle arrival at next node
            if node_nxt.is_customer():
                # capacity check
                if current_load + node_nxt.demand > self.graph.load_capacity + 1e-9:
                    return False
                current_load += node_nxt.demand

                # time window check
                if current_time < node_nxt.ready_time:
                    # wait
                    current_time = node_nxt.ready_time
                if current_time - 1e-9 > node_nxt.due_date:
                    return False

                # service time
                current_time += node_nxt.service_time

            elif node_nxt.is_station():
                # For simplicity follow nearest_neighbor logic: fully recharge
                # Optionally add realistic charging time:
                # required_energy = self.graph.tank_capacity - current_battery
                # charging_time = required_energy / self.graph.charging_rate
                # current_time = max(current_time, node_nxt.ready_time) + node_nxt.service_time + charging_time
                current_battery = self.graph.tank_capacity
                # respect station ready_time and service_time if provided
                if current_time < node_nxt.ready_time:
                    current_time = node_nxt.ready_time
                current_time += node_nxt.service_time

            elif node_nxt.is_depot():
                # reset vehicle state after return to depot
                current_load = 0.0
                current_battery = self.graph.tank_capacity
                current_time = 0.0
            else:
                # unknown node type -> fail-safe
                return False

        # final sanity: ensure route ends at depot
        if route[-1] != 0:
            return False

        return True
Ghi chú quan trọng:

_check_feasible() hiện giả định sạc đầy ngay lập tức tại trạm như nearest_neighbor_heuristic() trong evrptw_config.py. Nếu bạn muốn mô phỏng thời gian sạc theo năng lượng cần nạp, thay đoạn comment bằng tính charging_time = (Q - current_battery) / charging_rate, update current_time tương ứng.

Ham _check_feasible hien tai sac day tai tram. Neu muon partial recharge:

Thay tactic: khi den station, chi sac needed_energy = min(Q, energy_for_next_segment + safety_margin) va tinh charging_time = needed_energy / charging_rate.

Phuc tap tang len khi ham tai su dung nonlinear charging rates (thi phai linearlize hoac piecewise).

6.4 Pheromone update tiep can:
Sau khi ACS_DIST chay va local search thu duoc solution T_dist tien boi local search, phai global update tren T_dist (Graph.global_update_pheromone).

ACS_VEI con update in_j cho cac customer unvisited.
